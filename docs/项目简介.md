# 项目简介

项目名称：KernAdapt：面向混合负载的自适应内核资源管控 Agent

## 一句话介绍

KernAdapt 面向数据库与混合负载，依据锁等待、工具返回和服务目标选择资源配置，通过受限执行、效果评价与恢复过程组织可解释的 Linux 性能优化。

## 项目简介

KernAdapt 是面向数据库与混合负载的 Linux 自适应资源优化系统，为数据库运维、基础设施性能工程和代码工具平台提供观测、配置选择、执行验证与恢复能力。LockCoop 处理锁释放前的持锁者调度延迟与交接后的局部性；FlowCausal 利用工具实际返回依赖安排会话内执行；控制面根据应用目标比较方案并管理运行范围。256 线程 MariaDB OLTP 中，相对同机 scx_simple，openEuler ARM64 节点 0 吞吐为 5.30 倍、p95 降低 84.8%；x86 全机为 4.14 倍。600 次独立决策中有 147 次调整，114 次正收益，其余决定与结果完整保留。项目围绕源码入口、复现文档、依赖许可和贡献流程组织开源交付，并以固定场景案例支撑后续集成和维护。

## 主要创新

1. 用逐锁状态关联解锁前的持锁者推进与交接后的局部性放置。
2. 用实际工具返回关系和会话服务核算组织工作流调度。
3. 按用户目标比较组合资源配置，通过选择风险检查、受限执行与恢复管理调整。

## 核心关键词
