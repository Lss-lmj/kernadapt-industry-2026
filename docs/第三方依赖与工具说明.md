## 许可范围

根目录 MIT 许可用于对应原创控制面和文档；带 SPDX 的文件按文件级许可使用。LockCoop 等调度器文件保留 GPL-2.0 等标识，用户同步观测库及接口头保留 LGPL-2.1-or-later。复制或分发源文件时保留其版权与许可头。

| 组件 | 用途 | 来源与说明 |
| --- | --- | --- |
| Linux / sched_ext | 可编程调度接口、内核与示例工具构建基础 | [Linux 文档](https://docs.kernel.org/scheduler/sched-ext.html)；依相应源码的 SPDX / COPYING |
| libbpf / bpftool | BPF 加载、CO-RE、skeleton 与工具链 | [libbpf](https://github.com/libbpf/libbpf)、[bpftool](https://github.com/libbpf/bpftool)；依文件级许可 |
| Python / SQLite | 控制流程、状态记录与结果分析 | 外部运行环境，依对应发行版本许可 |
| LangGraph | 可选执行后端 | 外部安装；MIT；核心路径不以该可选后端为唯一入口 |
| MariaDB / Sysbench | 数据库和负载实验 | 外部实验软件，依所用版本许可；未将数据库实现作为原创代码 |

| OpenHarmony | 系统接入语义与技术资料 | [官方项目](https://github.com/openharmony)；组件按各自许可 |

## 原创贡献

LockCoop 的逐锁状态、有界持锁者推进、同锁交接放置与资源域锚定；FlowCausal 的返回关系维护、会话服务核算与有界提前执行；KernAdapt 的资源配置选择、效果评价及执行管理；相应实现、实验协议和结果分析构成项目主要工作。基础操作系统、数据库、工具链和第三方框架分别保留其上游来源。

## 人工智能与文档工具

Codex 用于辅助代码和文档编写、问题分析与测试脚本编写。参赛成员负责技术方案、代码审查、实验分析和最终内容。文档使用 LaTeX 排版，答辩文件使用 python-pptx 和 LibreOffice 导出。

## 模型、数据与实验软件

本材料包不包含模型权重、凭据、外部数据集镜像、完整 Linux 内核或数据库软件包。归档实验结果、合成控制面演示和实际系统运行分别按各自来源解释。使用结果时保留平台、工作量、基线、统计方法和引用。

许可文本见 `LICENSE` 与 `docs/licenses/`；具体源文件的 SPDX 清单以相应代码版本为准。
